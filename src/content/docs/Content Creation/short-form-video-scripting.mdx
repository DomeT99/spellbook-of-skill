## Description

This guide teaches the skills needed to write engaging short-form video scripts that capture attention fast and drive engagement.

## Guide

Write a [time] TikTok/Shorts script that explains [topic] in [language]. Include a hook, problem-solution structure, and call to action.

## Example

"Write a 60-second TikTok explaining what Git is in English."

**Hook (0-5 sec)**
"Ever lost your code? Deleted something by accident? Git fixes that."

**Problem → Solution (5-30 sec)**
"Git tracks every change in your project. Think of it as a time machine for your code."

**Key Features (30-50 sec)**
"Commit changes, create branches for new features, merge them back in."

**Call to Action (50-60 sec)**
"Start using Git today — it's free. Follow for more dev tips!"

---

## Explanation

### Key Skills

1. **Immediate Hook**: Capture attention in the first 3 seconds with a question or bold statement.
2. **Clear Structure**: Divide the script into logical sections (hook, problem, solution, CTA).
3. **Visual Direction**: Include visual cues in [brackets] to guide editing.
4. **Pacing**: Match the fast rhythm of short-form platforms.

### Best Use Cases

- ✅ Content creators scaling video production
- ✅ Developers explaining technical concepts
- ✅ Marketing teams producing educational content
- ✅ Brands building developer audience

### Tips for Best Results

- Specify precise details about the topic
- Customize the tone to match your brand
- Review and adapt the script before recording
